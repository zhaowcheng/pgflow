# Triage labels

工程 skills 使用五个标准 triage 角色。本文件将这些角色映射到本仓库 issue tracker 使用的字符串。

| `mattpocock/skills` 中的角色 | 本仓库使用的字符串 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 信息完整，可交给 AFK agent |
| `ready-for-human` | `ready-for-human` | 需要人工实施 |
| `wontfix` | `wontfix` | 不予处理 |

当 skill 提到某个 triage 角色时，使用上表对应的字符串，将其记录在 issue 文件的 `Status:` 行中。

如果本仓库以后改用其他词汇，只修改表格中“本仓库使用的字符串”一列。
